# Growth dashboard KPI contract

The admin dashboard should present aggregates only.

## Core cards
- Registered users
- Paid subscribers
- Registration-to-paid conversion
- Active learners (7d)
- Active learners (30d)
- Lesson completions (30d)

## Funnel cards (30d)
- Diagnostic started
- Diagnostic completed
- Trial started
- Trial exhausted
- Upgrade clicked
- Checkout started
- Subscription activated
- Subscription cancelled
- Payment failed
- Upgrade-to-paid conversion

Percentages are decimal ratios in the API response and formatted as percentages in the UI. QA sessions must not be treated as customer activity.
