# Tolux Lesson-Standard Audit — Modules 16–25

Audit basis: the owner-approved Tolux standard used for current Algebra 1 releases: visual-first teaching; actual graphs/coordinate planes whenever graph interpretation is part of the skill; comprehensive progressive help; Hint 3 answer + reasoning; useful Explain Another Way; immediate correct answer + full solution after a checked incorrect non-mastery attempt; a visible Review Solution & Continue path; mathematically equivalent-answer handling where the requested form permits it; 5/10/20 Practice Mode; first-attempt scoring; progress save/sync; and mastery integrity.

## Module 16 — A.2C Write Lines from Tables, Graphs, and Descriptions
**PASS after visual/grading retrofit.** The existing table/word translation instruction was strong. The graph portion is now an actual coordinate-plane line with a slope triangle and intercept marker rather than a text-only graph reminder. Simple equivalent slope-intercept term order such as `y=2+3x` is normalized to `y=3x+2` before grading.

## Module 17 — A.2D Direct Variation
**PASS.** Existing origin-centered graph and `y=kx` visual model remain. Practice already includes immediate full solution, Hint 3 reasoning, first-attempt scoring, and progress saving. Equivalent simple linear term order is accepted where applicable.

## Module 18 — A.2E Parallel Lines
**PASS.** Existing parallel-line visual clearly shows equal slopes and different intercepts. Lesson feedback now follows the current Review Solution & Continue behavior without revealing mastery answers prematurely.

## Module 19 — A.2F Perpendicular Lines
**PASS after visual retrofit.** The negative-reciprocal teaching is retained and now paired with an actual coordinate-plane graph showing two perpendicular lines and the right angle, so the visual rule and geometric meaning are taught together.

## Module 20 — A.2G Horizontal and Vertical Lines
**PASS.** Existing coordinate-plane visual distinguishes `y=c` from `x=c`, slope 0 from undefined slope, and axis relationships. Current attempt-flow behavior is aligned.

## Module 21 — A.2H Write Linear Inequalities in Two Variables
**PASS.** Existing visual includes the actual boundary line, dashed/solid meaning, test point, and shaded solution region. Equivalent simple RHS term order such as `y>5-2x` is normalized to `y>-2x+5` before grading. Context inequalities that intentionally use two variables retain their original structure.

## Module 22 — A.2I Write Systems of Linear Equations
**PASS.** Existing visual shows two equations as two graphed lines with their shared intersection. Systems continue to accept either equation order; the audit also normalizes harmless term order inside simple slope-intercept equations.

## Module 23 — A.3A Determine Slope
**PASS.** Existing coordinate-plane line with a visible rise/run triangle satisfies the visual standard. Practice already provides full solution reveal, Hint 3, Explain Another Way, first-attempt scoring, and saved progress.

## Module 24 — A.3B Rate of Change in Context
**PASS.** Existing distance-versus-time graph visibly labels Δ distance, Δ time, and units, connecting slope to contextual rate of change.

## Module 25 — A.3C Graph Linear Functions and Key Features
**PASS.** Existing coordinate-plane visual shows the y-intercept, x-intercept/zero, slope triangle, and graph-construction sequence.
